# Curso — Ingeniería de Software Agéntica para Seniors

Abre `index.html` en un navegador moderno.

## Incluye
- Curso autoguiado con navegación libre.
- Progreso persistente en `localStorage`.
- Animaciones CSS.
- Bloques de código con botón de copiar.
- Teclas ← / → para avanzar y retroceder.
- Material Markdown (`course.md`).
- Especificación del proyecto.
- JSON Schemas de `nota`, `tarea` y `liga`.
- Prompts reutilizables para Plan / Build / Review / Security.

## Proyecto
Entidades: aplicación multiplataforma para notas, tareas y ligas con CRUD, filtros, ordenamiento y editor schema-driven.

## Nota
Las herramientas y sus comandos evolucionan. Antes de instalar una versión concreta, verifica la documentación oficial.
