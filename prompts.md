Puedes crearme un curso de uso de inteligencia artificial aplicado al desarrollo de software en modo agentico con buenas practicas en arquitectura de software y seguridad. Para este curso, se debe considerar que es para desarrolladores/ingenieros senior que son de la vieja escuela y que tienen temores y celos a esta tendencia de desarrollo actual. El stack de tecnologías a utilizar es para mobile multiplataforma con react-native/expo con interfaz de usuario nativa con expo y tailwind en web. El formato del curso debe ser "multimedia enriquecido", en web, con animaciones, con texto en formado markdown para poder copiar y pegar ejemplos, con posibilidad de ir eligiendo el tema a aprender y poder avanzar y retroceder a discreción. El flujo del curso debe ser enfocado a autoaprendizaje para un programador con muchos años de experiencia y con esporádica colaboración con otros programadores de forma remota usando git y GitHub, pero primariamente como programador solitario. Que cubra casos de uso para sesiones de codigo con agentes IA usando `opencode` o `pi` como agentes y con modelos de eleccion propia, asi como gentle-ai (con engram y codegraph). El curso debe ser practico y el proyecto para desarrollar debe ser una aplicacion movil multiplataforma para tomar notas y gestionar tareas y ligas (a sitios web) con metadatos, esta aplicacion debe proveer un CRUD y un listado de "items" (notas, tareas, ligas) con filtros y ordenamiento dinamico. Ademas, el editor de cada "item" debe ser basado en un esquema de datos (JSON Schema) que describa sus campos y metadatos. A esto lo llamaremos "entidad", que define la estructura y los campos, su nombre ('nota', 'tarea', 'liga') y otros metadatos. Estos esquemas seran proporcionados en formato JSON durante el curso.
